# React Native Book Manager App

A React Native Expo app with Appwrite backend to create, update, and manage books with authentication, real-time database, and simple notifications.

## Features

- User Authentication
- Add Books
- Update Books
- Delete Books
- Real-time Database
- Notifications
- Responsive UI

## Tech Stack

- React Native
- Expo
- Appwrite
- JavaScript

## Installation

```bash
git clone https://github.com/your-username/react-native-book-manager-app.git
cd react-native-book-manager-app
npm install
npx expo start
