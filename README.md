# React Native Book Manager App

A modern mobile application built with React Native and Expo, integrated with Appwrite backend services for authentication and database management. The app enables users to securely register, log in, create books, fetch book data from the database, and delete books with a smooth and responsive user interface.

## Features

- User Registration Authentication
- User Login Authentication
- Secure Appwrite Backend Integration
- Add New Books to Database
- Fetch Books from Appwrite Database
- Delete Books from Database
- Real-time Database Operations
- Responsive and Clean UI
- Cross-platform Mobile Support with Expo
